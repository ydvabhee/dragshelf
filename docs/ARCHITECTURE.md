# DragShelf — Architecture

Status: v1 as built (synced with code 2026-10-23, T-01..T-20). Scope: `docs/PRD.md`. Tasks: `docs/TASKS.md`.

## 1. Stack
- Swift 6 language mode, strict concurrency, default actor isolation `MainActor` (ADR-011). Off-main callbacks: ADR-016.
- AppKit: shelf panel, drop destination, drag source and drag handles, event monitors, Quick Look, window move/resize.
- SwiftUI: shelf content, menu bar menu (`MenuBarExtra`), Settings window.
- Frameworks only from the SDK: AppKit, SwiftUI, Quartz (QuickLookUI), QuickLookThumbnailing, UniformTypeIdentifiers,
  ServiceManagement, CryptoKit, os, Carbon (hotkey only). **No third-party deps.**
- Toolchain on dev machine: macOS 26.5, Xcode 26.6, SDK macOS 26.5, Swift 6.3.3. Build with SwiftPM (ADR-013);
  `xcodebuild` is broken on this machine (OQ-15). No xcodegen/tuist.
- Deployment target: **macOS 14.0** (ADR-002).

## 3. Package, app bundle, and build settings
`Package.swift`:
- `// swift-tools-version: 6.2` (first manifest with `.defaultIsolation`; toolchain is Swift 6.3.3).
- `platforms: [.macOS(.v14)]`; `executableTarget(name: "DragShelf")`; `testTarget(name: "DragShelfTests", dependencies: ["DragShelf"])`.
- Both targets: `swiftSettings: [.defaultIsolation(MainActor.self), .treatAllWarnings(as: .error)]`. Swift 6 mode is the tools ≥ 6.0 default.
- Tests: Swift Testing (`@Test`, `#expect`), `@testable import DragShelf`, not hosted in the app. Pure logic plus AppKit
  objects that need no running `NSApplication` (e.g. `DropReceiver` with a fake `NSDraggingInfo`).

`scripts/build-app.sh [debug|release]` (default `debug`), `set -euo pipefail`:
1. `swift build -c <config>`.
2. Recreate `build/DragShelf.app`; copy the binary to `Contents/MacOS/` and `Resources/AppIcon.icns` to `Contents/Resources/`.
3. Write `Contents/Info.plist` (heredoc), keys below.
4. `codesign --force --sign - --options runtime` (ad-hoc, hardened runtime; no entitlements, no sandbox). M5 adds Developer ID + notarization here.

| `CFBundleIconFile` | `AppIcon` |
| `CFBundlePackageType` | `APPL` |
| `CFBundleShortVersionString` | contents of `VERSION` |

Commands (all must stay green on every commit):
```
swift build                      # debug, zero warnings
swift test                       # all Swift Testing tests pass
scripts/build-app.sh release     # release (-O) build + bundle; required, see below
open build/DragShelf.app         # run; never run the bare binary
```
- **Release build is required, not optional.** Swift 6.3 crashed only at `-O` (EarlyPerfInliner on the synthesized deinit of the
  generic `DropReceiver<Content>`). Workaround: explicit `nonisolated deinit {}` in `DropReceiver` (marked `ponytail:`, remove when the toolchain is fixed). Debug builds never show this class of bug.
- Always run the bundled app: `SMAppService`, `LSUIElement`, and the bundle id only work inside `DragShelf.app`.
- Cache paths use the constant bundle id string, not `Bundle.main.bundleIdentifier` (nil under `swift test`).
- Native arm64 only. Universal binary is an M5 concern (OQ-15).

## 5. Data flow
```
            drag starts in another app                         ⌃⌥⌘D / menu "Show DragShelf"
                    │                                                         │
       DragMonitor (global mouse monitors,                              HotKey / MenuBarExtra
        drag pasteboard changeCount)                                          │
                    └──────────── dragStarted ──► ShelfPanelController ◄──────┘
                                                   show(on cursor screen)
                                                         │
 drop on panel ─► DropReceiver ─► PasteboardReader ─► [Incoming]
                       │                                 │ file/url/text → store.add now
                       │                                 │ image data    → Task.detached: PNG into cache dir + SHA-256
                       │                                 │                 → back on main → store.add (drop order kept)
                       └ NSFilePromiseReceiver ─────────►│ promise       → receivePromisedFiles(promiseQueue)
                                                         ▼                 → nonisolated handler → Task @MainActor add
                                                    ShelfStore (@Observable)
                                                         │ observed by
                                                         ▼
                                       ShelfView / ShelfItemView / RecentList (SwiftUI, Glass)
                                                         │ mouseDragged in DragOutHandleView
                                                         ▼
                                     DragOutSource.begin(drag items | Recent row items)
                                                         │ session ends with operation
                                                         ▼
                        recordDragOut (Recent) → remove per ADR-017 (cache dirs kept) → hints.record
                                   store empty → ShelfPanelController.hide()
```

### Dedupe (`ShelfStore.add`, O(1))
- `Key`: `file(path)` (standardized, parent symlinks resolved once per add, so `/tmp` = `/private/tmp`), `url(absoluteString)`,
  `text(String)`, `image(SHA256.Digest)` when `contentHash` is set.
- Same file/url/text key → rejected (`false`; caller owns any cache dir). Same image hash → old item replaced, new one appended
  in one assignment (the shelf never looks empty mid-replace).
- `remove` and `clear` drop keys. No item limit (OQ-30).

### Ingest ordering (`DropReceiver.ingest`)
- A drop with no image and no ingest in flight adds synchronously.
- Otherwise it chains on `pendingIngest` (a `Task`), so items keep drop order. Each step checks `store.generation`: a Clear after the drop
  drops what has not landed. If nothing landed, `onPromiseFailed` runs (auto-hide treats it as "no drop").

### Panel visibility rules (ShelfPanelController)
1. `dragStarted` (monitor runs only when auto-show is on) → `show(reason: .autoDrag, at: cursor)`; sets `store.isDragging`.
2. `dragEnded` → after 250 ms grace, hide only if reason `.autoDrag`, no drop landed, store empty, no new drag (`shouldAutoHide`).
3. Hotkey → toggle, panel **key** (keyboard works without the mouse). Menu → toggle, panel non-key. Auto-show → non-key.
   No reason except `.autoDrag` is auto-hidden.
4. Store becomes empty (remove, drag out, clear) → hide.
5. Close button / Esc → hide, items kept.
6. Never `NSApp.activate` for the shelf. Only Settings activates the app.
7. Menu "Undo Drag Out" → restore newest Recent entry, then show.
- Show: refresh missing files, reset `showRecent`, record `.shown` hint event, refresh promos (not on `.autoDrag`), slide 10 pt + fade
  (`NSAnimationContext`) plus SwiftUI 0.96→1 top-anchored scale; Reduce Motion → fade only.

### Drag-start detection (DragMonitor)
- `.leftMouseDown`: remember drag pasteboard `changeCount` and point.
- `.leftMouseDragged`: if `changeCount` changed since mouse-down **and** cursor moved ≥ 10 pt **and** `PasteboardReader.canAccept` → `onDragStart`.
  Window moves/resizes and selection rectangles never write the drag pasteboard. Ignored while our own `DragOutSource.current` runs.
- `.leftMouseUp`, or the 100 ms button poll seeing the button up → `onDragEnd()`.
- Mouse global monitors need no permission (key monitors would; we use none).

### Drag out (ADR-017)
- Plain drag → mask `.copy`. ⌘ held **and every item is a file** → `[.move, .copy]` (copy-only receivers still accept). Mixed selection
  → copy. Inside our app → `[]`. `ignoreModifierKeys` = false, so toggling ⌘ mid-drag updates live.
- End: `[]` (cancel) → nothing. Any drop → `recordDragOut(batch)` (not for Recent-row drags). Remove when `.move`, or when dropped and
  `keepAfterDragOut` is off. Removal keeps cache dirs (targets read late; Recent holds them); a `.move` deletes the emptied cache dir.
- Recent-row drag: shelf items stay; only a `.move` removes shelf items whose key matches a moved file. The entry stays.
- Selection: dragging a selected tile drags the selection, an unselected tile drags alone, Drag All drags everything. Missing files never drag.

### Recent (T-17, ADR-018)
- `recent`: newest first, ≤ 5 entries, one per successful drag out (a Drag All of 30 files = 1 entry). Memory only.
- Header clock button (shown when Recent is non-empty) swaps the grid for `RecentList` in the panel. Row: icon, title ("photo.heic",
  "3 files", "3 items"), age, missing count. Click → `restore` (present items re-added with normal dedupe, entry removed). Drag → drag
  out its present items. All-missing rows are dimmed and inert. "Clear Recent" at the bottom.
- ⌘Z (key panel) or menu "Undo Drag Out" → `undoDragOut()` restores the newest entry.
- `showRecent` resets on every show, on items arriving, and on each accepted drop.

### Cache directory
- `ItemCache.root` = `~/Library/Caches/com.abhishekyadav.DragShelf/Shelf/`, one `root/<UUID>/<filename>` per cached item.
- Image data → `Image <yyyy-MM-dd HH.mm.ss>.png` (TIFF converted to PNG).
- Lifetime is shared between shelf and Recent: `release(_:)` deletes a dir only when no shelf item and no Recent entry uses it.
  - remove → released. Drag out → kept (Recent). Recent entry falls off / Clear Recent / restore → released.
  - Clear → `wipe(keeping:)` dirs still used by Recent. Launch and quit → whole root wiped.
- Original user files are referenced, never copied. The promo cache (`.../Promos/`) is outside `root`.

## 6. UI design (Apple HIG)
- **Branding (T-19):** commands, titles, tooltips, and VoiceOver labels that name the panel say **"DragShelf"** ("Show DragShelf",
  "Clear DragShelf", "Remove from DragShelf"), never a bare "Shelf". Code identifiers keep `Shelf*` names.
- Size: default width 360 pt (3 columns); user-resizable from the bottom, side edges, and bottom corners (top edge = move area).
  Min 176 × (header + 1 tile row + footer row); max = screen `visibleFrame`. Columns adapt: as many 80 pt tiles as fit.
- Height fits content (min 160 pt + footer row), top edge fixed, async after each geometry change. Cap = the user's resized height on that display,
  else min(4.5 tile rows + footer row, 50% of `visibleFrame` height). The tip/promo footer row (28 pt) is always reserved, so a tip never grows the panel; beyond the cap the grid scrolls. New items scroll into view.
- Header: Drag All (`square.stack.3d.up`, drag handle), title ("DragShelf" empty / "N Items" / "Recent"), Recent
  (`clock.arrow.circlepath`, only when Recent exists), **Clear** (text button, no trash icon; files untouched), Close (`xmark`).
  Empty header area drags the window (`WindowDragView`, clamped to `visibleFrame`); double-click = Reset Position.
- Grid: `LazyVGrid`, tile = 64 pt thumbnail + 2-line `.caption` (middle truncation). Hover shows the `xmark.circle.fill` remove badge.
  Missing files are dimmed with a "Missing" label. Empty state: `tray.and.arrow.down` + "Drop here".
- Footer slot: one line under the grid, a tip or a promo (§12, §13). Fixed 18 pt row. During any drag it goes transparent but
  keeps its height, so the panel never resizes under the pointer.
- **macOS 26:** `.glassEffect(.regular, in: 22 pt continuous rect)`, drop target tinted with accent 25%; header buttons
  `.buttonStyle(.glass)` circles in a `GlassEffectContainer`. Thumbnails are content, not glass.
- **macOS 14–15:** `NSVisualEffectView` (`.popover`, `.behindWindow`, `state = .active`), 16 pt rounded `maskImage`; buttons borderless.
- All availability branches for styling live in `Glass.swift` (`shelfBackground`, `shelfButtonStyle`, `ShelfGlassContainer`,
  `flashScrollIndicators`, `shelfCornerRadius`).
- Reduce Transparency → solid `windowBackgroundColor`. Increase Contrast → 1 pt `separatorColor` stroke inset 1 pt, selection ring.
- No focus ring anywhere (`.focusEffectDisabled()`, `focusRingType = .none`). Scroll bar forced to overlay style, inset from the
  rounded corners (`contentMargins`). Content view layer clips to the corner radius so no square edge or shadow shows.
- Motion: tile insert/remove `.scale + .opacity`; Reduce Motion → opacity only everywhere.
- VoiceOver: tile "<type description>, <name>", actions Remove / Quick Look; "Item added" and tips announced at low priority.
- Fonts: system only. Icons: SF Symbols, except the menu bar glyph and app icon, which are drawn in code (ADR-021).

## 7. Permissions and security
- **None requested.** No Accessibility, Input Monitoring, Full Disk Access, Screen Recording.
- Global mouse monitors and Carbon hotkeys work without TCC permission. If QA ever sees a prompt, it is a bug.
- Files dropped by the user are readable without TCC prompts (user-intent grant), including Desktop/Documents/Downloads.
- Network: only the promo feed (§12): one HTTPS GET to a hardcoded URL, at most once per 24 h (3 h after a network error), none when
  promos are off. No identifiers, no analytics, no cookies. No user data leaves the machine.
- Cache dir holds copies of promised/image content only; wiped per §5.
- **Drag out never moves a user's file unless the user holds ⌘** and every dragged item is a file (ADR-017). A plain drag is copy-only.

## 8. Distribution and versioning
- Dev: `scripts/build-app.sh` ad-hoc signs (`codesign -s - --options runtime`). Hardened runtime on now, so M5 needs no code change.
- `scripts/make-dmg.sh`: release build → `build/DragShelf.dmg` (UDZO, volume "DragShelf <VERSION>", `Applications` symlink).
- Versioning (rules in `CLAUDE.md`): `VERSION` is SemVer (now `0.1.0`); build number = git commit count. Every user-visible
  `feat`/`fix` adds a `CHANGELOG.md` `[Unreleased]` line. Release = move Unreleased to a dated section, bump `VERSION`,
  `chore(release): vX.Y.Z` + tag, `make-dmg.sh`, user pushes, then `gh release create` with asset `DragShelf.dmg`.
  The README links to the Releases page (`releases/latest`), never a direct file.
- Preview builds are ad-hoc signed, not notarized (README explains Open Anyway).
- M5 (**BLOCKED on user**): Developer ID Application cert, `notarytool` credentials → Developer ID sign → notarize → staple. App Store/sandbox: future ADR.
- `SMAppService.mainApp` (launch at login) works best from `/Applications`; QA tests it from there.

## 9. Risks
| Risk | Mitigation |
|---|---|
| Global `.leftMouseDragged` monitor may not fire during some apps' drag sessions | Mouse-down baseline + button poll; QA matrix; fallback = hotkey/menu |
| AppKit calls a MainActor-inferred closure off main → Swift 6 runtime trap (seen: `receivePromisedFiles` reader, `NSImage` drawing handler) | ADR-016: `nonisolated` + `@Sendable`, off-main tests, QA checklist item |
| `-O`-only compiler crash (generic `NSHostingView` subclass deinit) | `nonisolated deinit {}`; release build in every task's checks (§3) |
| `NSHostingView` intercepting drags | Resolved: the hosting view itself is the drop destination (`DropReceiver` subclass); no SwiftUI drop modifiers |
| First click in the inactive non-activating panel lost by SwiftUI gestures | AppKit handle views with `acceptsFirstMouse` (`DragOutHandleView`, `WindowDragView`) |
| Material looks inactive in non-key panel (14–15) | `NSVisualEffectView.state = .active` |
| Quick Look needs a key window without activating app | `canBecomeKey` on non-activating panel; preview ordered front, `hidesOnDeactivate = false` |
| Slow/large file promises | Background `OperationQueue`; item added when written; 250 ms hide grace; `generation` check vs Clear |
| `xcodebuild` broken (stale DVTDownloads framework, exit 70) | SwiftPM build (ADR-013); user may run `sudo xcodebuild -runFirstLaunch` (OQ-15) |
| Hotkey ⌃⌥⌘D taken by another app | `register()` returns false and logs; menu still works; custom recorder later (OQ-04) |
| Promo feed URL is a placeholder | OQ-26 must be answered before release (T-12) |

## 10. ADRs
- **ADR-001: Native Swift 6 + AppKit/SwiftUI, no third-party deps.** Why: small app, all needed APIs are in the SDK, native look. Rejected: Electron/Catalyst (non-native drag plumbing), SPM packages for hotkeys/launch-at-login (SDK covers both).
- **ADR-002: Deployment target macOS 14.0; Liquid Glass on macOS 26 via `#available`.** Why: macOS 14 gives `@Observable`, `SettingsLink`, `MenuBarExtra`, `SMAppService`, and covers most active Macs; one availability file (`Glass.swift`) gives the macOS 26 look. Rejected: macOS 26-only (drops many users for one styling branch), macOS 13 (loses `@Observable`).
- **ADR-003: Hand-written `DragShelf.xcodeproj`. Superseded by ADR-013.** Why (then): no xcodegen/tuist on machine. Rejected (then): SPM executable, installing xcodegen.
- **ADR-004: No sandbox; Developer ID + notarization; ad-hoc signing in dev; hardened runtime on.** Why: sandbox needs security-scoped bookmarks and complicates promises/global monitors. Rejected: Mac App Store for MVP.
- **ADR-005: SwiftUI `App` lifecycle with `MenuBarExtra` + `Settings`; shelf is an AppKit `NSPanel`.** Why: least code for menu bar + settings; `NSPanel` is required for non-activating floating behavior. Rejected: `NSStatusItem` + manual settings window, SwiftUI `Window` scene for the shelf.
- **ADR-006: Drop destination in AppKit, not SwiftUI `onDrop`/`dropDestination`.** Built as `DropReceiver: NSHostingView` so the content view is both the SwiftUI host and the destination. Why: needs `NSFilePromiseReceiver` and full pasteboard access; one view avoids the hosting view swallowing drags. Rejected: SwiftUI drop APIs (weak promise support), a separate `NSView` wrapping the hosting view (drag interception risk).
- **ADR-007: Drag out copy-only. Superseded by ADR-017.** Why (then): protect originals (OQ-05).
- **ADR-008: Drag detection = global mouse monitors + `NSPasteboard(name: .drag).changeCount`.** Why: no permission needed, ignores window drags. Rejected: `CGEventTap` (needs Input Monitoring/Accessibility), shake gesture (non-goal).
- **ADR-009: Global hotkey via Carbon `RegisterEventHotKey`, fixed ⌃⌥⌘D.** Why: only permission-free global hotkey API. Rejected: `NSEvent` global key monitor (needs Accessibility), KeyboardShortcuts package (ADR-001).
- **ADR-010: Items in memory only; cache wiped on launch/clear/quit. Superseded by ADR-018** (memory-only still holds; Clear now keeps dirs Recent uses).
- **ADR-011: Swift 6 mode, default actor isolation `MainActor`, warnings as errors.** Why: app is UI-bound; fewer annotations; zero-warning rule enforced by the compiler. Off-main work uses `Task.detached` / `nonisolated` and hops back to main (rules: ADR-016).
- **ADR-012: Images and promised files are materialized to cache files; `ShelfItem.Kind` = file/url/text.** Why: one drag-out path, real files work in every target. Image dedupe uses `contentHash` (OQ-16). Rejected: separate image kind with in-memory `NSImage`.
- **ADR-013: SwiftPM package + `scripts/build-app.sh` instead of an `.xcodeproj` (supersedes ADR-003).** Why: `xcodebuild` exits 70 on this machine (stale `DVTDownloads`); the fix needs `sudo`. `swift build`/`swift test` work, compile `.glassEffect` behind `#available`, run Swift Testing. A short script gives the bundle, Info.plist, icon, and signing. Rejected: keep xcodeproj (cannot build or test), wait for the user, xcbuild backend / universal `--arch` (route through the broken Xcode build system).
- **ADR-014 (v2): Shelf Actions use native tools only and produce new cached items.** Zip = `/usr/bin/ditto` via `Process`; Share/AirDrop = SwiftUI `ShareLink` + `NSSharingService(named: .sendViaAirDrop)`; Convert/Resize = ImageIO; Rename = rename the shelf copy (APFS clone into the cache), never the original. Work runs off `MainActor`, one job at a time, cancellable. Why: no deps (ADR-001), originals never touched, outputs reuse the cached-file drag-out path (ADR-012). Rejected: `NSFileCoordinator` `.forUploading`, ZIPFoundation/libarchive, Apple Archive, `NSImage`/Core Image resize, libwebp, renaming originals in place (OQ-17).
- **ADR-015: "More apps" promo = static JSON feed over HTTPS, text only, hardcoded URL + host allowlist, opt-out toggle (T-14, §12).** Why: new apps must appear without a DragShelf update. A static file needs no server code. Text + SF Symbol only: no remote images (no tracking pixels, no decoder attack surface). Rejected: own API server, remote images/HTML/`WKWebView`, CloudKit, Sparkle-style appcast or any package, list bundled in the app.
- **ADR-016: Off-main AppKit callbacks must be `nonisolated` and `@Sendable` under MainActor default isolation.** With `.defaultIsolation(MainActor.self)` every closure is MainActor-inferred unless marked; Swift 6 inserts a runtime isolation check, so AppKit calling it on another thread traps before the body runs. Seen: the `receivePromisedFiles` reader (called on `promiseQueue`; app quit on a VS Code image drop) and `NSImage(size:flipped:drawingHandler:)` (menu bar glyph, glass mask). Rule: any closure or method AppKit/Foundation may call off main (promise readers, image drawing handlers, notification selectors that may post off main, URLSession delegates) is built in a `nonisolated` func and typed `@Sendable`; it captures only `Sendable` values and hops to main with `Task { @MainActor in }` or `DispatchQueue.main.async` + `MainActor.assumeIsolated`. Main-thread-only callbacks (Carbon app target, `Timer` on main, Quick Look control) use `MainActor.assumeIsolated` instead. Enforced by: QA checklist item on every task (TASKS implicit ACs), off-main tests (`OffMainDrawTests` draws the images on a global queue; promise handler tested via `finishPromise`). Rejected: `@preconcurrency` / `nonisolated(unsafe)` to silence checks (hides the trap, not the bug), dropping MainActor default isolation (many more annotations).
- **ADR-017: Drag out = copy by default; ⌘ + all-file drags offer `[.move, .copy]` (T-15, supersedes ADR-007).** Writers stay `NSURL` / `NSString`; no `NSFilePromiseProvider` (cached content is already a real file). Mask is computed per callback from live modifiers; mixed selections copy (AppKit has no per-item masks). `.move` always removes the item (the file left its folder), even with "Keep items after drag out" on; other drops remove unless that setting is on. Removed items keep their cache dirs for Recent. Why: Finder convention (⌘ = move), user request; plain drags still never touch originals. Rejected: Shift as modifier (not Finder), honoring Finder's own ⌥/⌘ semantics on a plain drag (could move a file without intent), always offering `.move`.
- **ADR-018: Recent = last 5 drag-out batches, memory only, shown in the panel (T-17, supersedes ADR-010).** Items still never persist across quit (OQ-03). Cache-dir lifetime is shared between shelf and Recent (§5): a dir goes only when neither uses it; Clear keeps Recent's dirs; launch/quit wipe all. The list replaces the grid inside the panel, not an `NSPopover`. Why: a wrong drop or failed upload otherwise loses the item (items leave after drag out, OQ-08). A popover window is not non-activating: clicking it would activate DragShelf and break rule 6. Rejected: `NSPopover` / separate window (activation), persistent history (non-goal), more than 5 entries (cache growth).
- **ADR-019: Placement = top center by default, drag header to move, drag edges to resize, remembered per display (T-13, T-16).** No position preference/picker. `UserDefaults` `panelOffsets` = [display UUID: [dx, dy]] (top-center offset from `visibleFrame` top center), `panelSizes` = [display UUID: [w, h]]; display UUID from `CGDisplayCreateUUIDFromDisplayID` (name fallback). Saved spots clamp into `visibleFrame`. User height = max height; content still fits below it. Reset (menu, Settings, header double-click) forgets both. Why: users wanted to move it anywhere; per-display memory survives reboots and display reordering. Rejected: edge/position picker (fewer options, more UI), `isMovableByWindowBackground` (conflicts with tile drag out), per-screen index (changes with display order).
- **ADR-020: One footer slot shared by tips and promos; tip wins (T-18).** `HintEngine` is local only (UserDefaults counts, no network), shows one line at a time, never during a drag, each tip ≤ 3 times, ✕ retires it. Why: one quiet line keeps the panel calm and its height stable. Rejected: popovers/coach marks (modal, activation), two footer lines.
- **ADR-021: Menu bar glyph and app icon are drawn in code.** `MenuBarIcon` draws an 18 pt template image (card dropping into a tray) at runtime; `scripts/make-icon.swift` renders the 1024 pt app icon, `make-icon.sh` builds `Resources/AppIcon.icns` (committed). Why: no asset catalog with SwiftPM + no Xcode (ADR-013); resolution-independent; glyph matches the icon. Rejected: SF Symbol `tray.and.arrow.down` (generic, did not match the icon), PDF/asset catalog (needs Xcode tooling).

## 11. v2: Shelf Actions design (BACKLOG)
Scope: `docs/PRD.md` §10 (US-11..US-14). Tasks: `docs/TASKS.md` v2 backlog. Not built in v1.

New files (all under `Sources/DragShelf/Actions/` unless noted):
| Type | Kind | Responsibility |
|---|---|---|
| `ActionRunner` | `@Observable final class` (MainActor) | Holds the single running job: `title`, `progress: Double?` (nil = indeterminate), `error: String?`. `run(_ title:, work: @Sendable (ProgressReporter) async throws -> [URL])` starts a `Task`, adds each returned URL to `ShelfStore` as `.file` with `isCached = true`, selects the outputs. `cancel()` cancels the task. Drops results if `store.generation` changed (Clear during a job) |
| `Zipper` | `enum`, `nonisolated` static funcs | `zip(_ urls: [URL], into dir: URL) async throws -> URL`. 1 source: `ditto -c -k --sequesterRsrc --keepParent <src> <dir>/<name>.zip`. 2+ sources: clone each into `<dir>/stage/` (`FileManager.copyItem`, APFS clone on the same volume), then `ditto -c -k --sequesterRsrc <dir>/stage <dir>/Archive.zip` (contents at top level), then delete `stage/`. `Process` args as an array, never a shell string. Cancel → `withTaskCancellationHandler { process.terminate() }` |
| `ImageConverter` | `enum`, `nonisolated` static funcs | `convert(_ src: URL, to type: UTType, maxPixel: Int?, into dir: URL) throws -> URL`. `CGImageSourceCreateWithURL` → `CGImageSourceCreateThumbnailAtIndex` with `kCGImageSourceCreateThumbnailFromImageAlways`, `kCGImageSourceCreateThumbnailWithTransform` (upright), `kCGImageSourceThumbnailMaxPixelSize` = `min(maxPixel, source longest edge)` (no upscale) → `CGImageDestinationCreateWithURL` + `kCGImageDestinationLossyCompressionQuality = 0.85` for JPEG/HEIC. No source properties copied (strips GPS/EXIF); the color space stays with the `CGImage`. Alpha → JPEG: draw onto white in a `CGContext` first. `writableTypes` = `[.heic, .jpeg, .png, .tiff]` ∩ `CGImageDestinationCopyTypeIdentifiers()` |
| `Renamer` | `enum`, `nonisolated` static funcs | `validate(_ name:) -> String?` (error text or nil). `rename(_ item:, to name:, cache:) throws -> ShelfItem`. Cached item: `moveItem` inside its own item dir. Original: `cache.newItemDir()` + `copyItem` (clone) to `<dir>/<name>`, result `isCached = true`. Same `id` so position and selection stay |
| `ActionsMenu` | SwiftUI view (`UI/ActionsMenu.swift`) | Menu content used by both the header "Actions" menu and the tile context menu: Compress, Rename…, Share… (`ShareLink`), AirDrop, Convert To ▸, Resize ▸. Target = selection if non-empty (or clicked item for context menu), else all |

`ShelfStore` gets one new method: `replace(id:with:)` (Rename; keeps index, selection, and the `keys` entry in sync).

Data flow: menu → `ActionRunner.run` → `Task.detached` work writes into `store.cache.newItemDir()` →
returns output URLs → back on `MainActor` → `store.add(ShelfItem(kind: .file(url), isCached: true))` → user drags it out.
On failure or cancel, the job deletes its own item dir before returning.

Rules:
- Files produced by actions live in `ItemCache` and follow its lifecycle (§5).
- Actions never write outside `ItemCache`; sources are only read.
- Off-main work follows ADR-016.
- Progress: zip is indeterminate (ditto reports none); convert reports `done/total`; rename is indeterminate and shown only if it takes > 300 ms.
- UI: while a job runs, the header shows a small `ProgressView`, the job title, and a Cancel (`xmark.circle`) button. Errors show as a one-line caption under the header until the next action or Close. VoiceOver announces start/finish via `AccessibilityNotification.Announcement`.
- Rename edits text, so the panel must become key (it can: `canBecomeKey` is true). It must not activate the app.
- Share/AirDrop: the picker and AirDrop sheet are owned by our app. If they do not appear in front from a non-activating panel, call `NSApp.activate()` only for this action (the same exception as Settings, §5 rule 6). While the sheet is open, auto-hide rules must not hide the panel.

v2 risks:
| Risk | Mitigation |
|---|---|
| AirDrop sheet or share picker appears behind other apps from a non-activating panel | Spike first in V2-02; fallback: activate the app for this action only |
| Renaming a large original across volumes is a full copy (slow, uses disk) | Runs as a cancellable job with progress; same-volume copies are APFS clones (instant, no extra space) |
| Zipping 2+ items cross-volume copies them into `stage/` first | Same as above; ponytail ceiling documented in `Zipper`; upgrade = `ditto` per item into a shared archive if it matters |
| ImageIO writers differ by OS (HEIC encode needs hardware support on some Macs) | Menu lists only `writableTypes` computed at runtime |
| Text field inside a SwiftUI grid in an `NSPanel` loses focus on drag-out handle views | Rename task verifies keyboard focus with the `DragOutHandleView` overlays in place |

## 12. "More apps" promo feed (T-14, v1)
Scope: PRD US-15. ADR-015.

### Feed
- Static JSON over HTTPS. URL and allowed hosts are **hardcoded constants** in `PromoConfig` (`PromoFeed.swift`). Placeholder until the user answers OQ-26: `https://example.com/dragshelf/promos.json`, hosts `["example.com"]`.
- Schema: `backend/promos.schema.json`. Example: `backend/promos.json`. The publisher validates the file before upload.

| Field | Type | Rule (client drops the entry if broken) |
|---|---|---|
| `version` | Int | Must be `1`. Any other value → ignore the whole feed, keep the last good cache |
| `promos` | Array | ≤ 20 entries kept, rest ignored; duplicate ids after the first dropped |
| `id` | String | `^[a-z0-9-]{1,40}$`; key for ✕ dismiss |
| `title` | String | 1–60 chars (≤ 120 scalars), no control/format/line-separator scalars (`\n`, bidi overrides) |
| `subtitle` | String? | ≤ 80 chars, same character rule; empty = none |
| `url` | String | `https`, host exactly in `allowedHosts`, no port, no user/password, ≤ 2048 chars |
| `symbol` | String? | SF Symbol name ≤ 64 chars; ignored (not the entry) if `NSImage(systemSymbolName:)` is nil |
| `minAppVersion` / `maxAppVersion` | String? | `MAJOR.MINOR[.PATCH]`, inclusive, compared to `CFBundleShortVersionString`; unparsable → entry dropped |
| `startsAt` / `endsAt` | String? | ISO 8601; shown when `startsAt ≤ now < endsAt`; unparsable → entry dropped |
| `excludeBundleIds` | [String]? | ≤ 20 entries, each ≤ 255 chars. Hidden in apps whose bundle id is listed, so DragShelf never promotes itself |

Unknown fields are ignored. Body > 64 KB → rejected.

### Client
| Type | Kind | Responsibility |
|---|---|---|
| `PromoConfig` | `nonisolated enum` | `feedURL`, `allowedHosts`, limits, `selfBundleID`, `isAllowed(_ url:)` (the one URL check for fetch, redirect, and open) |
| `PromoFeed` / `Promo` | `nonisolated struct`, `Sendable` | `decode(_:) -> PromoFeed?` decodes leniently per entry (`FailableEntry`), then `Promo.init?` validates. `eligible(now:appVersion:bundleID:dismissed:)` sorted by `id`. `pick(from:now:calendar:)` = `eligible[dayOrdinal % count]` (daily rotation) |
| `PromoLoader` | `@Observable final class` | `init(session:cacheURL:defaults:now:)`; loads the disk cache at init (offline launch shows last good feed). `footerPromo` (dismissed skipped), `menuPromos` (dismissed included), `dismiss(_:)`, `static open(_:)`, `refreshIfStale()` |
| `PromoFooter` | SwiftUI view | One line: optional symbol, `title`, `subtitle` (`.tertiary`, tail truncation), ✕. Line is one `Button` with `.help(url)`; a11y "<title>, <subtitle>. Opens in browser"; ✕ "Hide this suggestion" |

Fetch (`refreshIfStale`, called at launch, on toggle-on, and on each non-auto-drag panel show):
- No-op when `showPromos` is off, a fetch is running, or `promoLastFetch` is < 24 h old (a future date counts as stale).
- `promoLastFetch` is set to now **before** the request: server errors, bad feeds, and refused redirects wait 24 h. A `URLError`
  (offline, timeout; not cancel) rewinds it so the next try comes after 3 h.
- Session: ephemeral, no cookie storage/acceptance, no `urlCache`, no credential storage, 15 s request / 30 s resource timeout.
  Request: `User-Agent: DragShelf/<CFBundleShortVersionString>`, `Accept-Language: en`, no cookies,
  `If-None-Match: <promoETag>` only when a cached feed exists. Tests inject a stub `URLProtocol` session.
- Response: final URL must pass `isAllowed`. 304 → keep cache. 200 → stream bytes, abort past 64 KB (also checks `expectedContentLength`)
  → `decode` → write `<caches>/com.abhishekyadav.DragShelf/Promos/feed.json` atomically + store ETag. Anything else → keep cache,
  `Logger(category: "promos").error`.
- Redirects: `RedirectGuard` (`nonisolated`, `Sendable` delegate) follows only to an allowed URL; otherwise cancels.

Opening a promo: re-check `isAllowed` at click time, then `NSWorkspace.shared.open(url)`. Never other schemes. Does not activate DragShelf.

Display rules:
- Footer row under the grid, shared with tips; a tip wins (ADR-020). The grid cap subtracts the row height, so the panel never exceeds its max.
- Not shown when `showPromos` is off or no eligible promo. During any drag (`isDragging`, `isDropTargeted`) it is transparent, not hit-testable, hidden from VoiceOver, and keeps its height.
- ✕ adds the id to `dismissedPromoIDs`; the footer then shows the next eligible promo, if any. Dismissed promos still appear in "More Apps".
- "More Apps" submenu: one item per eligible promo, hidden when the list is empty or promos are off.

## 13. Tips (T-18)
Scope: PRD US-17. ADR-020. `Model/HintEngine.swift`, `UI/PromoFooter.swift` (`HintFooter`).

| Hint (priority order) | Trigger | Text |
|---|---|---|
| `clear` | Clear with ≥ 1 item | "Clear only empties DragShelf; your files aren't touched." |
| `dragOut` | Drag out that removed items | "Removed from DragShelf · ⌘Z to bring it back" |
| `firstDrop` | Any drop on the panel | "Switch apps, then drag items out of DragShelf." |
| `hotkey` | Menu show (`.manual`), 2nd time or later; only while the hotkey is on | "Tip: ⌃⌥⌘D shows DragShelf from anywhere." |
| `recent` | Any recorded drag out, or a show with Recent non-empty | "Recent drags are under the clock icon." |
| `holdCommand` | Show with ≥ 1 file item | "Hold ⌘ while dragging out to move instead of copy." |
| `moveResize` | 3rd panel show or later | "Drag the top bar to move DragShelf · edges to resize." |

- Events add eligible hints to `pending`; when the panel is visible and no drag runs, the top-priority pending hint becomes `current`,
  its count goes up, and `pending` clears. Hidden panel → `current` cleared.
- Eligible = `showTips` on, not dismissed, shown < 3 times. ✕ → `dismissedHints`. Settings "Reset Tips" clears all keys and the current tip.
- UserDefaults keys: `hintCounts`, `dismissedHints`, `panelShowCount`, `menuShowCount`.
- `HintFooter`: `lightbulb` + one `.caption` line, ✕ "Dismiss tip"; VoiceOver reads "Tip: …" with key symbols spelled out and the
  controller announces it. Reduce Motion → fade only.
